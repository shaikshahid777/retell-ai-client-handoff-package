# Evidence

Screenshots used to verify this project were taken from the live Retell, n8n and Google Sheets UIs and contain browser address bars, instance host names, spreadsheet IDs and account details.

**Do not upload them as-is to a public repository.** If you add screenshots, crop or blur those details first and place the cleaned copies in `evidence/screenshots/`. Keep the originals private.

What each screenshot verifies is listed in `assessment/evidence-and-limitations.md`.
